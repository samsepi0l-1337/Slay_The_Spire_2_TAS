두 건 모두 독립 재현과 수정은 아직 수행하지 않았다. 리뷰 지적과 확인된 수정 결과를 혼동하지 않는다.

   `PlayCardAction` enqueue 직후 같은 snapshot이 다시 수신되면 `chosen`을 지워 보상이 유실되거나 중복 명령이 발생할 위험이 지적됐다. 변화 또는 명시적 acknowledgement까지 pending을 보존하는 경계를 검토하고 회귀 테스트로 재현해야 한다.
2. [적 slot 재배열에서 처치 보상 유실](https://github.com/samsepi0l-1337/Slay_The_Spire_2_TAS/pull/11#discussion_r4227242065), `src/sts2_tas/live.py:100`.

## 미완료 검증·제약

- `ssh -o BatchMode=yes -o ConnectTimeout=10 sts2-windows hostname`을 3회 시도했으며 모두 exit `255`, timeout이었다. Tailscale 대상은 offline 상태였다.
- Windows SSH를 통한 실제 게임 attach·named pipe·명령 적용 검증은 필수 미완료 항목이다. Windows CI 성공은 이를 대체하지 않는다.
- Docker daemon이 없어 이미지 build/run은 미검증이다.
- C# runtime coverage 및 실제 게임 동작은 미검증이다. Python 100% coverage나 C# compile 결과로 이를 대신 주장하지 않는다.
